# Cat Life 🐾

A beautiful personal website to track your cat profiles — breed, age, personality, weight, and more.

Built with pure HTML, CSS, and JavaScript. No frameworks, no backend — stores data in your browser's `localStorage`. Deploy for free on **GitHub Pages**.

## Features

- ➕ Add, edit, and delete cat profiles
- 🔍 Search by name or breed
- 🎨 Track coat color, gender, age, weight
- 💬 Personality trait tags (Playful, Cuddly, Talkative, etc.)
- 📷 Photo support (via URL)
- 📊 Live stats (total cats, unique breeds, average age)
- 💾 Auto-saves to localStorage
- 📱 Fully responsive
